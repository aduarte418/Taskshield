# Taskshield
Repo para el miniproyecto Taskshield de Desarrollo Servidor


Instrucciones de ejecución (más detalladas en doc/README.md): 

1. Clonar el repositorio para tener el proyecto en local.
2. Abrir XAMPP y arrancar el servidor Apache y MySQL.
3. Acceder a phpmyadmin pulsando "admin" en la fila MySQL el panel de control de XAMPP (hipervínculo básico: http://localhost/phpmyadmin/index.php?route=/database/structure&db=taskshield).
4. Acceder a http://localhost/Taskshield/.
5. Realizar operaciones como añadir, editar o eliminar incidencia.
